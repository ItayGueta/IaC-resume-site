How I Work

Five principles. No checklists.

01

Agentic Architecture

Skills compose into tools. Tools register on MCP servers. Subagents fan out. Workflows orchestrate. I know the stack top to bottom — and where each piece belongs.

02

Token Economics

Right model for the right task. Cache hits over fresh calls. Cost-per-invocation tracked. Budgets enforced.

03

Workflow Design

Pipeline vs. barrier. Find → verify → fix → review. Adversarial checking. Loop-until-dry.

04

Tool Craft

Narrow enough to never misfire. Broad enough to earn its schema real estate.

05

Prompt Engineering

Structured output schemas. Few-shot that earns its token cost. Real constraints, real results.
